User Rundown (Features they’ll interact with)

Toolbar (Top Bar)

App name: Worship Helper PRO (branding always visible).

Scene Switcher: dropdown / selector to swap between saved scenes.

Scene Import: button to import a scene JSON file.

Light/Dark Mode Toggle: instantly switches between modes with gradient backgrounds.

Left Sidebar (Layers Panel)

Shows all elements in the current scene, stacked like layers:

Each text element.

Background element.

A slide layer.

Clicking a layer selects it → loads its editable properties into the properties panel.

Canvas (Center Stage)

Displays the live preview of the selected scene.

Elements update in realtime as properties are modified.

Background styles (color, gradient, image) update instantly when changed.

Text styles (color, font, weight, outline, etc.) update instantly.

Slide animation preview triggers when configured.

Right Sidebar (Properties Panel)

Text Properties

Text color

Font weight (200–900)

Outline (color + width)

Font size

Font family (select dropdown)

Background Properties

Background style: plain, gradient, image

Plain → background color

Gradient → type (linear, radial, conical), number of stops, color pickers

Image → upload, pick from server, live preview update

Background-size, attachment, repeat, etc.

Slide Properties

Entrance animation (3 presets) + duration + easing

Exit animation (3 presets) + duration + easing

Bottom Panel (Runtime Details)

Current scene name

Number of elements

Switching scenes

🔹 Developer Rundown (How it works, what to know)
File Structure
index.html   → main UI (single-page app)
css/style.css   → styling (dark gradient theme, light mode override)
js/app.js   → core logic, WebSocket handling, API integration

Core Concepts

Scenes Array (thescenes)

Populated via /api_getscenes (returns {success, echo}).

If API fails, defaults to a fallback scene.

Each scene object looks like:

{
  scenename: "Default",
  scenetemplate: "<div class='content versedisplay'>...</div>",
  myelements: [
    { mytype: "text", demotext: "Sample Verse" },
    { mytype: "background", demotext: "" }
  ],
  datecreated: "2025-08-16T12:00:00Z"
}


Realtime Updates

Property changes update both:

The canvas DOM (live preview).

The scene’s stored styles in memory.

Properties Binding

Selecting a layer populates the right panel with inputs tied to the element’s styles.

Events (oninput/change) propagate updates instantly.

WebSocket

Global variable socket for WS connection.

Function sendMessage(msg) sends payloads.

API Endpoints

/api_getscenes → fetch scenes

/api_uploadimg → uploads image, returns new path

/api_getimages → fetch list of available images

/api_stylesmanager → accepts style payloads via POST

Payload Structure

{
  "scene": "Scene1",
  "txtstyles": { "txt_color": "#fff", "txt_fontweight": 600 },
  "bgstyles": { "bg_style": "image", "bgdata": { "bg_d_src": "path/to/img" } },
  "slidestyles": { "slide_entrance": "fade", "slide_duration": 2 }
}


Light/Dark Mode

CSS class toggle on <body>.

Default: dark mode (with gradient background).

Smooth transitions handled via transition: 0.3s.

Tutorial Modal

Simple overlay with step-by-step instructions.

Stored in localStorage so it only auto-shows the first time.

Runtime Panel

Reads directly from thescenes + selected scene object.

Updates automatically when scene changes.

✅ Dev Tips

Add new style properties by:

Extending the property panel HTML (right sidebar).

Binding oninput to update scene.myelements and canvas.

Add new API endpoints by extending app.js fetch handlers.

Debugging WebSocket messages? Check sendMessage() in app.js → all messages pass through there.

Scene import/export works with plain JSON, so you can back up scenes or share them across setups.
