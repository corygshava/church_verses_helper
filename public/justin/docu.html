User Rundown Features they’ll interact with

Toolbar (Top Bar)

  • App name: Worship Helper PRO – branding always visible.
  • Scene Switcher: dropdown to swap between saved scenes.
  • Scene Import: button to import a scene JSON file.
  • Light/Dark Mode Toggle: instant switch with gradient backgrounds.

Left Sidebar (Layers Panel)

Shows every element in the current scene—text, background, slide layer—stacked like layers. Clicking a layer selects it and loads its properties into the right panel.

Canvas (Center Stage)

Live preview of the selected scene. All style or animation changes update in real-time.

Right Sidebar (Properties Panel)

  • Text: color, font-weight (200–900), outline, size, family.
  • Background: plain, gradient (linear, radial, conical), or image. Full-size, repeat, attachment controls.
  • Slide: entrance/exit animations (3 presets each) with duration & easing.

Bottom Panel (Runtime Details)

Current scene name, number of elements, date created, active mode (Light/Dark).

Modal Tutorial

Auto-opens on first load; covers scene switching, text & background editing, and exporting. Triggerable again via menu.

Send Button

Transmits current scene styles as JSON via POST /api_stylesmanager and mirrors the payload through WebSocket sendMessage().

Developer Rundown How it works

File Structure

index.html   → main SPA
css/style.css → dark-gradient theme + light override
js/app.js     → core logic, WebSocket, API glue

Core Concepts

  • thescenes array – populated from /api_getscenes; falls back to a default scene.
  • Scene object shape: 
    {
  scenename: "Default",
  scenetemplate: "<div class='content versedisplay'>...</div>",
  myelements: [
    { mytype: "text", demotext: "Sample Verse" },
    { mytype: "background", demotext: "" }
  ],
  datecreated: "2025-08-16T12:00:00Z"
}

Realtime Updates & Property Binding

Selecting a layer populates the right panel. oninput/change events instantly update both the DOM canvas and the in-memory scene object.

WebSocket

Global socket variable. sendMessage(msg) centralizes all outbound WS traffic—handy for debugging.

API Endpoints

  • /api_getscenes – initial scene list
  • /api_uploadimg – upload image, returns new path
  • /api_getimages – list of available images
  • /api_stylesmanager – accepts style payloads via POST

Payload Structure Example

{
  "scene": "Scene1",
  "txtstyles": { "txt_color": "#fff", "txt_fontweight": 600 },
  "bgstyles": { "bg_style": "image", "bgdata": { "bg_d_src": "path/to/img" } },
  "slidestyles": { "slide_entrance": "fade", "slide_duration": 2 }
}

Light/Dark Mode

CSS class toggle on <body>; default dark with smooth 0.3 s transitions.

Tutorial Modal & Runtime Panel

Modal visibility tracked in localStorage. Runtime panel reads directly from thescenes and updates on every scene change.

Dev Tips Quick wins

  • Add new style properties by extending the right-panel HTML and binding oninput to update scene.myelements & canvas.
  • New API? Add another fetch handler in app.js.
  • Debug WebSocket traffic via sendMessage()—every payload passes through it.
  • Scene import/export is plain JSON—back up or share scenes easily.
