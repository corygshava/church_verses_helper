Quick Tour

Goal: Style scenes for verses quickly. Left = Layers, Middle = Canvas live preview, Right = Properties.

Select a layer in the left panel to reveal its properties. “slide” layer controls enter/exit animations.

Background styles: Plain color, Gradient (linear/radial/conic), or Image (upload/pick). Live previews.

Payload: Use Send Payload to POST to /api_stylesmanager and broadcast via WebSocket.

Shortcuts: Ctrl+Z undo, Ctrl+Y redo. Click “Preview Enter/Exit” to test animations.

Import/Export: Top bar buttons. Scenes autosave to localStorage.
